# Capability matrix (2026-10-16)

Every capability the owner asked for, where its code is, which Bondok tool reaches it, and the evidence. Built from
the full-path review of 2026-10-16 (four parallel audits) and updated after the fixes. Evidence layers are kept apart:
**offline** = deterministic test in `tests/` (fakes, no network); **LA-n** = real model through Bondok's conversation
path on an isolated synthetic store (`tests/live_agent_check.py`, 19 cases); **LV** = the meaning verifier on 155
owner sentences with the real model (`tests/live_verifier_check.py`); **AS** = the owner-approved live acceptance run
through Slack on dedicated test items (`tests/acceptance_script.py`); live publishing evidence is real approved posts
only (see `bondok-agent-migration/08-tracker.md`). A simulated test is never called live publishing.
