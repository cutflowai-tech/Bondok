# خطة تحويل بندق إلى إيجنت كامل الصلاحيات وإلغاء n8n

تاريخ الخطة: 14 أكتوبر 2026. الحالة: خطة تنفيذ مقترحة؛ لم يُعدّل الكود أو الإنتاج.

## النتيجة المطلوبة
تكلم بندق فيفهم وينفّذ عبر APIs: يقرأ ويعدّل Monday، يتعامل مع الملفات، يسجّل تأكيداتك، يجهّز الفيديو، يجدول وينشر ويراجع النتائج. قواعد العمل تفضيلات يملكها صاحب المشروع ويستطيع تغييرها أو استثناء حالة منها. تختفي n8n من التشغيل بعد نقل وظائفها والتحقق من البديل.

## أساس الخطة وحدودها
الخطة مبنية على وصف المشروع المرفق في المحادثة ومشكلتك مع تأكيد Topaz، وليست مراجعة للمستودع. أسماء الملفات الحالية المذكورة نقاط بحث متوقعة وليست حقائق تحققنا منها. المرحلة 0 تراجعها قبل اتخاذ قرارات حذف أو إعادة كتابة. قدرات APIs وصلاحيات الحسابات وحدود المنصات تُتحقق من توثيقها الرسمي والحساب الفعلي أثناء التنفيذ؛ أسماء الأدوات في هذه الخطة واجهات داخلية مقترحة وليست أسماء endpoints رسمية.

## ترتيب التنفيذ المختصر
- P0: إثبات الوضع الحالي وحصر كل مسؤوليات n8n.
- P1: إصلاح السلطة أولًا؛ تأكيد Topaz وتغيير القواعد بأمر المالك.
- P2: بناء أدوات APIs موثوقة فوق الكود القابل لإعادة الاستخدام.
- P3: تشغيل الإيجنت بصلاحيات فعلية وذاكرة أوامر.
- P4: نقل التجهيز والجدولة والنشر إلى تشغيل دائم بدون n8n.
- P5: إثبات السلوك في الأعطال والمواقف الحقيقية.
- P6: انتقال الإنتاج وإزالة n8n.

تبعيات المراحل: P0 → P1 → P2 → P3 → P4 → P5 → P6. يمكن تطوير اختبارات كل مرحلة معها؛ لا تنتظر P5 لتبدأ الاختبار.

## أول شريحة تسلّم للمستخدم
بعد P1 ووصلة تنفيذ صغيرة من P2: تقول «أنا عملت توباز للفيديو ده»، فيسجّل بندق تأكيدك على النسخة المحددة، يعيد تقييم الجاهزية، ويحدّث Monday بدون اشتراط اسم ملف. وتقول «شيل شرط توباز للفيديو ده» فيسجّل استثناءً لا ادعاءً بأن المعالجة حدثت.

## تعريف انتهاء المشروع
كل وظائف workflows القديمة لها بديل مثبت؛ بندق يملك أدوات التنفيذ الفعلية؛ أوامر المالك تغيّر القواعد وتستثني منها؛ النشر المجدول يعمل والشات مغلق؛ نتائج النشر الغامضة تُدار بدون تكرار أعمى؛ استعادة الحالة مجرّبة؛ n8n لا تشغّل أي وظيفة لبندق ولا تحتفظ باعتماد نشط خاص به.

## طريقة العمل
استخدم معرفات المهام في commits ونتائج الاختبار. لا تضع علامة إنجاز إلا مع دليل. احتفظ بما يعمل من waset_ops، وانقل المسؤولية بدل إعادة كتابة كل شيء. لا تغيّر مواعيد أو شروط العمل افتراضيًا أثناء الترحيل؛ انقلها كإعدادات قابلة لأمر المالك. هذه الوثائق تفوّض التخطيط فقط؛ تنفيذ نشر حي أو انتقال إنتاج يتبع تفويض المالك الفعلي وقت التنفيذ.
