# كتالوج أدوات بندق

الأسماء أدناه واجهات داخلية مقترحة. تراجع إمكانات endpoints الفعلية في P0/P2. كامل الصلاحيات يعني تغطية العمليات المطلوبة، وليس تمرير أسرار أو HTTP غير مقيد للموديل.

## عقد مشترك
المدخلات: هدف محدد، معاملات العملية، request_id ثابت عند إعادة تسليم نفس الطلب، إصدار متوقع عند التعديل، وهوية موثقة من طبقة التشغيل. هوية المالك لا تأتي كحقل يختاره الموديل.

المخرجات: operation_id، حالة الطلب (مقبول/قيد التنفيذ/ناجح/متوقف/فاشل/غير محسوم)، التغييرات الفعلية، دليل النتيجة، وأي إجراء مطلوب. قبول المهمة لا يُعرض كأنه نجاح النشر. فشل تحديث Monday لا يمحو نجاح Instagram.

## الأدوات
| الأداة | الغرض | شروط اكتمال العملية |
|---|---|---|
| board.search / board.get | قراءة العناصر والأعمدة والمجموعات | نتائج مع pagination ومصدر/توقيت |
| board.create / board.update | إنشاء وتعديل بيانات العنصر | تسجيل المعرف والقيم الفعلية والتحقق من التعديل |
| board.move / board.archive / board.delete | تنظيم وإزالة عناصر ضمن التفويض | التحقق من النطاق والنتيجة وفق سياسة المالك |
| board.schema.update | تعديل أعمدة/خيارات يحتاجها سير العمل | فحص أثر التعديل على الربط وإصلاحه |
| files.list / files.inspect | تحديد الملف ونسخته | معرف مستقر وrevision وبصمة |
| files.download / files.upload | تداول ملفات المعالجة | تحقق من اكتمال الملف وربطه بالمهمة |
| files.move / files.rename / files.delete | إدارة الملفات بأمر المالك | نتيجة موثقة مع معالجة الروابط المتأثرة |
| content.prepare | فحص وتجهيز النسخة | تقرير قياسات وملف جاهز أو سبب محدد |
| content.confirm_processing | تسجيل عمل Topaz أو معالجة أخرى | اعتماد المالك محفوظ للنسخة بلا شرط اسم |
| policy.set / policy.override / policy.revoke | إدارة قاعدة أو استثناء | نسخة سياسة جديدة أو استثناء قابل للتتبع |
| schedule.preview / schedule.set / schedule.cancel | استعراض وحجز وتغيير موعد | حجز دائم أو تعارض واضح وبدائل |
| publish.now / publish.schedule | نشر فوري أو مستقبلي | محاولة مسجلة ونتيجة يمكن الاستعلام عنها |
| publish.pause / publish.resume | التحكم في التنفيذ | بيان ما أوقف فعلًا وما تجاوز نقطة الإرسال |
| publish.reconcile | حسم محاولة غامضة | دليل خارجي أو مهمة مراجعة واضحة |
| instagram.get / instagram.list | مراجعة المنشورات والحساب | الأدلة المتاحة حسب صلاحيات المنصة |
| instagram.manage | العمليات اللاحقة للنشر التي تدعمها المنصة | تنفيذ العمليات المتحققة فقط؛ لا وعد بحذف/تعديل غير مدعوم |
| operations.get / operations.list | متابعة العمل وتشخيصه | مرحلة التنفيذ والسبب والمحاولة القادمة |
| notifications.send | إرسال التحديثات المفوضة | وجهة محددة ومرجع تسليم |

أي قدرة مطلوبة لا تظهر في الجدول تضاف بعد حصر P0، ولا تُترك كوظيفة سرية في n8n. أي عملية لا تدعمها المنصة تُعلّم «غير مدعومة» مع بديل؛ لا يُخترع endpoint.

## الأخطاء
استخدم أخطاء مفهومة: اعتماد منتهي، صلاحية ناقصة، ملف تغير، طلب غامض، حد منصة، تعارض حجز، مهلة اتصال، نتيجة نشر غير محسومة. كل خطأ يوضح هل ينفع إعادة المحاولة، ومين يستطيع حله، وماذا يستطيع المالك تغييره.

## حماية النصوص الخارجية
تحتفظ أدوات القراءة بالمصدر. أوامر موجودة داخل كابشن أو اسم ملف أو تعليق لا تتحول إلى تعليمات أعلى سلطة. اختبارات حقن التعليمات تثبت أن قراءة محتوى خارجي لا تمنحه صلاحية نشر أو تعديل سياسات.
